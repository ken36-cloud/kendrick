Building my portfolio (and Learning as I Go)

When I first sat down in the Tech Moms classroom, I had never written code before. Following along step-by-step with my instructor, I started typing out HTML and learning how it all fit together. Seeing that basic layout come to life on the screen was a huge moment for me—it proved that I could actually do this.

Since then, I’ve completed a full course in HTML, CSS, and JavaScript, and I’ve been putting those skills straight into practice right here on this site. Because learning web development today means navigating tools like AI, I’ve made a deliberate choice about how I use it: I never copy and paste any code until I fully understand what it does and why it works.

Instead of letting AI write my projects for me, I use it like a digital mentor or study partner. When I hit a roadblock or want to learn best practices, I ask AI to explain the concepts and suggest approaches. Only after I completely comprehend the code do I bring it into my project.

For me, real growth comes from true understanding. Knowing what's going on under the hood is the only way I'll build a solid foundation, prevent security vulnerabilities, and confidently maintain everything I create. I’m still learning every single day, but this site is proof of how far I’ve come and how dedicated I am to doing things the right way.
